# Elektronika – notatki do Garmina

Notatki z dwóch wykładów Elektronika2008UE i Elektronika2009UE, ułożone pod poprzednie kolokwia.

- `garmin/01-05`: komplet teorii.
- `garmin/06-07`: 27 rzeczywistych pytań i wariantów z poprzednich lat (z odpowiedziami).
- `garmin/08-09`: 33 dodatkowe pytania z odpowiedziami.
- `garmin/10`: najważniejsze wzory, liczby i wskazówki do wykresów.

**Podłącz w aplikacji Markdown notes / WristDown wyłącznie folder `garmin`, nie cały katalog główny.** Tak nie zsynchronizujesz pełnego długiego kompendium ani README.

Wszystkie pliki są zapisane jako UTF-8 Markdown. Wzory są zapisane w prostym tekście (np. `sqrt`, `pi`, `delta`), aby nie wymagały renderowania LaTeX. Poszczególne notatki nie przekraczają limitu 10 000 znaków podawanego dla części zegarków.

To materiały do nauki, z ograniczeniami i sprostowaniami oznaczonymi w tekście. Tranzystory i wzmacniacze występują w planie przedmiotu, ale nie w treści przekazanych dwóch wykładów.
